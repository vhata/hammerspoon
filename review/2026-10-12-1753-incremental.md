## Invariants

Carried from the full review, amended:

1. Module state lives in `local`s. Accidental globals leak across reloads and between modules. Exception: `reloadFallbackWatcher` in `init.lua`, declared in `.luacheckrc` with its reason. luacheck now enforces the rule for first-party code.
2. Anything that must keep running or stay usable (event taps, watchers, timers, modals, choosers, canvases, webviews) is held by a reference that outlives the function that created it, or Lua's garbage collector stops it. Still violated by `expanse-chooser-gc`.
3. Callbacks run on Hammerspoon's main thread. A blocking call (`hs.execute`, synchronous URL fetch, slow AppleScript) freezes every hotkey, and because the leader's event tap sees every `keyDown`, it delays typing system-wide.
4. Event taps that return `true` swallow the event system-wide; they must be narrow and removed when their overlay closes.
5. Transient UI takes global keys only while visible and only for the exact combination it means (Escape without modifiers, not every keycode 53). `floatcalendar-global-hotkeys` was fixed in eaeb098; open instances: `overlay-escape-ignores-modifiers`, `aclock-escape-swallow`, and new `floatcalendar-keys-taken-off-space` ("visible" includes being on the current Space).
6. Shell scripts under `set -euo pipefail` never let a no-match `grep` inside a command substitution or pipeline end the script. Both instances are fixed; the scripts now live in `docket/scripts/` and are vendored, so this invariant is the docket skill's to keep, and a regression arrives by resync.
