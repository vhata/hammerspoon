## Summary

The Lua config is in reasonable shape after the bug-fix round of 2026-10-08: no accidental globals (checked with `luac -l`), every long-lived tap, modal, timer and canvas is referenced, overlays centre correctly on any display, and the FloatCalendar date logic is correct across every month from 1901 to 2400 in twelve time zones. The one real defect in the modules is the expanse chooser, which nothing references while it is open. The remaining module findings are small input-handling edges in the leader and overlays, and main-thread blocking that has not been observed to bite.

The workflow scripts carry the most concrete bugs: two `pipefail` paths that exit 1 without a message, one of which `review-due.sh` will hit as soon as this review's index row exists, and a churn threshold that vendored code makes unreachable. These scripts are identical to the repo-workflow skill's bundled copies, so fixes belong upstream as well. Documentation was accurate apart from five small drifts, fixed on this branch.

## Invariants

Carried from `ARCHITECTURE.md`, amended; invariants 2 and 5 are carried back into `ARCHITECTURE.md` in c517ce9, and invariant 6 concerns the workflow scripts, so it lives here and in `workflow-script-silent-exits`:

1. Module state lives in `local`s. Accidental globals leak across reloads and between modules.
2. Anything that must keep running or stay usable (event taps, watchers, timers, modals, choosers, canvases, webviews) is held by a reference that outlives the function that created it, or Lua's garbage collector stops it. Violated by `expanse-chooser-gc`.
3. Callbacks run on Hammerspoon's main thread. A blocking call (`hs.execute`, synchronous URL fetch, slow AppleScript) freezes every hotkey, and because the leader's event tap sees every `keyDown`, it delays typing system-wide.
4. Event taps that return `true` swallow the event system-wide; they must be narrow and removed when their overlay closes.
5. New: transient UI takes global keys only while visible and only for the exact combination it means (Escape without modifiers, not every keycode 53). Three instances so far: `floatcalendar-global-hotkeys` (TODO), `overlay-escape-ignores-modifiers`, `aclock-escape-swallow`.
6. New: shell scripts under `set -euo pipefail` never let a no-match `grep` inside a command substitution or pipeline end the script; append `|| true` or wrap it. Two instances: `review-due-silent-exit-no-churn`, `pr-markers-silent-exit-remaining-from`.

## Findings

### Open and Moved

#### Bug

- `expanse-chooser-gc` — **The text-expansion chooser is held only by a function-local, so the garbage collector can release it while it is open.** Bug · Open · Read.
  - Where: `expanse.lua:50` (`pick_expanse`).
  - Severity: P2.
  - After `pick_expanse` returns nothing references the `hs.chooser` userdata; upstream `libchooser.m` `userdata_gc` releases the completion callback reference once its self-reference count reaches zero, so a collection while the picker is open (the leader's tap allocates an event object on every keystroke) leaves a selection that does nothing. Each Cmd+Alt+E also creates another chooser. Create one chooser at module level, as `Spoons/Emojis.spoon` does with `obj.chooser`, and refresh `:choices()` before each `:show()`.
  - Review backlog: `expanse-chooser-fixes`
- `expanse-truncate-utf8` — **Shortening a long expansion for the chooser subtext can cut a multibyte character in half.** Bug · Open · Verified.
  - Where: `expanse.lua:37-39` (`get_expanses`).
  - Severity: P3.
  - `#` and `sub` count bytes, so either cut point can split a character, including the 3-byte `↵` that `expanse dump` substitutes for newlines. Reproduced with Lua 5.5: `string.rep("ab↵", 40)` truncated by the same expression gives a 100-byte string for which `utf8.len` returns nil. Cut with `utf8.offset` instead.
  - Review backlog: `expanse-chooser-fixes`
- `leader-tap-ignores-mouse` — **Two right-Shift or right-Ctrl clicks within half a second open the leader.** Bug · Open · Verified.
  - Where: `leader.lua:138` (`M.tap`).
  - Severity: P3.
  - The tap listens only to `flagsChanged` and `keyDown`, so a mouse click between modifier press and release does not cancel the pending tap; two right-Shift range selections open the root layer, which then swallows the next `o`, `a`, `?` or Escape. Reproduced by agent 1 with a stubbed `hs` feeding four right-Shift `flagsChanged` events 0.15 s apart: the root modal entered and the alert showed. Add mouse-down and scroll events to the tap and reset state on them, as the `keyDown` branch does.
  - Review backlog: `leader-stray-input`
- `overlay-escape-ignores-modifiers` — **While an overlay is open, every Escape combination is swallowed system-wide.** Bug · Open · Read.
  - Where: `overlay.lua:31` (`o.toggle`, the `escTap` callback).
  - Severity: P3.
  - The tap matches keycode 53 regardless of flags and returns `true`, so Cmd+Escape, Option+Escape and similar never reach the focused app while the cheatsheet or leader help is shown. Check that `e:getFlags()` is empty before swallowing.
  - Review backlog: none (inventory)
- `review-due-silent-exit-no-churn` — **`review-due.sh` exits 1 without a verdict whenever nothing outside the docs changed since the reviewed commit.** Bug · Open · Verified.
  - Where: `scripts/workflow/review-due.sh:93` (`churn_since`).
  - Severity: P2.
  - Under `pipefail` the `grep -Ev` in `churn_since` returns 1 on empty input and `set -e` ends the script, although its header says it always exits 0. Reproduced in a temporary clone with an index row at `e3cde21` and no later commits: it printed only the `latest review:` line and exited 1 (the independent reviewer reproduced it at this branch's head, dying at `changed_src=`). This will happen on the first run after this review lands. Append `|| true` inside the pipeline.
  - Review backlog: `workflow-script-silent-exits`
- `pr-markers-silent-exit-remaining-from` — **`check-pr-markers.sh` exits 1 with no message when a remainder entry lacks a backticked `Remaining from:` line.** Bug · Open · Verified.
  - Where: `scripts/workflow/check-pr-markers.sh:138` and `:159` (the `Remaining TODO` and `Remaining review backlog` cases).
  - Severity: P2.
  - The `grep -oE` in each `orig="$(...)"` substitution finds nothing, `pipefail` plus `set -e` ends the script, and the intended "has no Remaining from line" error is never printed. Reproduced by agent 3 with `Remaining from: adopt-luacheck` written without backticks: exit 1, no output. Add `|| true` inside both substitutions.
  - Review backlog: `workflow-script-silent-exits`

## Verification limits

- No Hammerspoon runtime was available to the reviewers. Hammerspoon API behaviour was checked against the installed app's Lua sources (1.1.1) where they exist and against upstream source for compiled modules (`hs.chooser` garbage collection). `expanse-chooser-gc` in particular is inferred, not observed.
- FloatCalendar date logic was exercised in a stubbed harness on Lua 5.5 rather than Hammerspoon's 5.4: every month from 1901 to 2400 and every day from 2020 to 2030 as "today", in twelve time zones, against an independent Gregorian and ISO-week implementation, with mutation checks. No errors apart from `os.time` raising for dates before 1900 and for a skipped local day in Pacific/Kiritimati in 1995, both unreachable in practice. A suspected DST error in the month-length calculation was ruled out: `os.time` defaults to noon when no hour is given.
- `hs.canvas` nested writes such as `canvas[58].frame.x = ...` were confirmed to reach the canvas in the installed `canvas.lua` element metatable.
- `Emojis:init` loads an `hs.image` for each of its 2,676 PNGs on every reload; the cost was not measured and is not recorded as a finding.
- `check-pr-markers.sh --pr` against a live PR and `cleanup-landed.sh --apply` were not run.
