## Invariants

Carried from the previous review, amended:

1. Module state lives in `local`s. Accidental globals leak across reloads and between modules. Exception: `reloadFallbackWatcher` in `init.lua`, declared in `.luacheckrc` with its reason. luacheck enforces the rule for first-party code.
2. Anything that must keep running or stay usable (event taps, watchers, timers, modals, choosers, canvases, webviews) is held by a reference that outlives the function that created it, or Lua's garbage collector stops it. Still violated by `expanse-chooser-gc`.
3. Callbacks run on Hammerspoon's main thread. A blocking call (`hs.execute`, synchronous URL fetch, slow AppleScript) freezes every hotkey, and because the leader's event tap sees every `keyDown`, it delays typing system-wide. It does not kill the tap: upstream `libeventtap.m` re-enables a tap that macOS disabled by timeout.
4. Event taps that return `true` swallow the event system-wide; they must be narrow and removed when their overlay closes.
5. Transient UI takes global keys only while visible, on the current Space as well as on screen, and only for the exact combination it means. Open instances: `overlay-escape-ignores-modifiers`, `aclock-escape-swallow`, `floatcalendar-keys-taken-off-space`, and new `overlay-keys-taken-off-space`.
6. Shell scripts under `set -euo pipefail` never let a no-match `grep` inside a command substitution or pipeline end the script. The scripts that had it are vendored in `docket/scripts/`; the invariant is the docket skill's to keep.
7. `init.lua` starts `reload.lua` before any other load, so a load that fails part-way still reloads on the next change.
8. No Spaces-aware `hs.window.filter` (`setCurrentSpace`, `defaultCurrentSpace`, a `currentSpace` filter field). Nothing in the config breaks it.
